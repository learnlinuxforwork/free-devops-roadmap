1Package your capstone app as a Helm chart

Scaffold and structure
helm create roadmap-api
roadmap-api/
  Chart.yaml
  values.yaml
  templates/
    deployment.yaml
    service.yaml
    ingress.yaml
Templating the Deployment with values.yaml instead of hardcoding
# templates/deployment.yaml (excerpt)
spec:
  replicas: {{ .Values.replicaCount }}
  template:
    spec:
      containers:
        - name: api
          image: "{{ .Values.image.repository }}:{{ .Values.image.tag }}"
Install and upgrade
helm install roadmap-api ./roadmap-api -n roadmap \
  --set image.tag=v2 --set replicaCount=3
helm upgrade roadmap-api ./roadmap-api -n roadmap --set image.tag=v3
helm rollback roadmap-api 1 -n roadmap    # instant rollback to a prior revision
Checkpoint

The exact same chart, with only --set overrides changed, deploys cleanly to a second namespace as a 'staging' environment — that's what templating buys you over raw manifests.

2Set up ArgoCD or Flux for a GitOps deployment flow

Install ArgoCD
kubectl create namespace argocd
kubectl apply -n argocd -f \
  https://raw.githubusercontent.com/argoproj/argo-cd/stable/manifests/install.yaml
Point it at your capstone repo instead of running helm/kubectl by hand
apiVersion: argoproj.io/v1alpha1
kind: Application
metadata: { name: roadmap-api, namespace: argocd }
spec:
  source:
    repoURL: https://github.com/<you>/capstone-project.git
    path: charts/roadmap-api
    targetRevision: main
  destination:
    server: https://kubernetes.default.svc
    namespace: roadmap
  syncPolicy:
    automated: { prune: true, selfHeal: true }

This flips the deployment direction: instead of a pipeline pushing changes into the cluster, ArgoCD continuously pulls from Git and reconciles the cluster to match. Git becomes the single source of truth — kubectl edit against the live cluster gets silently reverted by selfHeal, which is exactly the point.

Checkpoint

Change replicaCount in the chart's values file, push to main, and watch ArgoCD apply it within its sync interval with zero manual kubectl commands.

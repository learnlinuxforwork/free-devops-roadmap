## Deployment architecture

- Image: multi-stage Docker build, distroless final stage, scanned in ECR on push
- Orchestration: EKS, node groups + Karpenter for spot/on-demand mix
- Delivery: Helm chart, deployed via ArgoCD from the `main` branch (GitOps)
- Scaling: HPA on CPU (2-10 replicas), Karpenter for node capacity
- Resilience: readiness/liveness probes, PodDisruptionBudget (minAvailable: 2)

Phase 4 exit criteria

The capstone app runs on real EKS, scales under load without you touching kubectl, survives a node drain without downtime, and redeploys automatically on a Git push. Phase 5 assumes this deployment target exists — it builds the CI/CD pipeline that produces the image and triggers the Git push that ArgoCD picks up.

2Review Lambda, API Gateway, and CI/CD service limits and quirks

Limits worth having memorized cold
Lambda: 15 min max execution, 10GB max memory, 250MB deployment package (zipped)
API Gateway: 29 second max integration timeout (a hard wall Lambda's 15 min can't get around)
CodeBuild: default build timeout 60 min, configurable up to 8 hours
ECR: no hard image size limit, but layer count and pull latency both degrade past ~a few GB
Checkpoint

Explain why a Lambda function behind API Gateway effectively has a 29-second timeout regardless of its own configured timeout — this exact gap is a recurring exam question and a recurring real production surprise.

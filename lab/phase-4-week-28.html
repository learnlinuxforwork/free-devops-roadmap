1Docker Compose for multi-container apps

A compose file wiring the capstone app together
services:
  api:
    build: .
    ports: ["8080:8080"]
    environment:
      DATABASE_URL: postgres://app:app@db:5432/roadmap
    depends_on:
      db:
        condition: service_healthy
  db:
    image: postgres:16
    environment:
      POSTGRES_USER: app
      POSTGRES_PASSWORD: app
      POSTGRES_DB: roadmap
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U app"]
      interval: 5s
    volumes:
      - db-data:/var/lib/postgresql/data
volumes:
  db-data:
Everyday compose commands
docker compose up -d
docker compose logs -f api
docker compose exec db psql -U app -d roadmap
docker compose down             # stop and remove containers, keep volumes
docker compose down -v          # also remove volumes -- start completely fresh
Checkpoint

The API container waits for the database to report healthy before starting — confirm this by running docker compose up and watching the log order, not just assuming depends_on handles it (a plain depends_on without a health check only waits for the container to start, not to be ready).

2Push images to Amazon ECR; image scanning basics

Create a repo and authenticate
aws ecr create-repository --repository-name roadmap-api

aws ecr get-login-password --region us-east-1 | \
  docker login --username AWS --password-stdin <ACCOUNT_ID>.dkr.ecr.us-east-1.amazonaws.com
Tag and push
docker tag roadmap-api:v1 \
  <ACCOUNT_ID>.dkr.ecr.us-east-1.amazonaws.com/roadmap-api:v1
docker push <ACCOUNT_ID>.dkr.ecr.us-east-1.amazonaws.com/roadmap-api:v1
Image scanning — catch known CVEs before they ship
aws ecr put-image-scanning-configuration \
  --repository-name roadmap-api --image-scanning-configuration scanOnPush=true

aws ecr describe-image-scan-findings \
  --repository-name roadmap-api --image-id imageTag=v1
Common trap

A distroless or scratch-based final stage (from Week 27) doesn't just shrink the image — it also shrinks the attack surface ECR has to scan. Fewer packages means fewer possible CVEs by construction.

1Sit the AWS Certified DevOps Engineer – Professional (DOP-C02) exam

Booking checklist
1. aws.training -> schedule via Pearson VUE
2. 180 minutes, 75 questions, scored 100-1000, passing score is 750
3. This is a Professional-level exam -- budget real rest before it, not a late-night cram
The finish line

54 weeks ago this started with installing Rocky Linux and learning to read a file permission string. Everything since has been building toward being able to design, automate, secure, and operate a real cloud-native system — not memorize trivia about one. The capstone repo is the proof; the cert is the forcing function that made sure nothing got skipped.

2Update your resume and LinkedIn with certs plus the capstone project link

What actually moves the needle on a resume, in priority order
1. The capstone repo link itself -- not "see GitHub," the actual project URL
2. RHCSA + the highest AWS cert you earned (Professional > Associate > Practitioner)
3. One line per major skill area with a concrete number where possible:
   "Reduced deploy time from manual (~30min) to automated GitOps (~4min) via ArgoCD"
4. Skip listing every tool touched -- list the 6-8 that map to the jobs you're targeting
Checkpoint

Have the resume reviewed by someone in The Hood or a mentor before sending it anywhere — the same 'explain it to someone else' check you ran on the README in Week 49-50 applies here too.

The 6 DOP-C02 domains, mapped to exactly where you built the skill
1. SDLC Automation              -> Phase 5 (CI/CD pipelines, deployment strategies)
2. Configuration Management/IaC -> Phase 3 (Terraform, CloudFormation) + Phase 7 (Ansible)
3. Resilient Cloud Solutions    -> Phase 2 (HA/DR, Multi-AZ) + Phase 4 (K8s scaling)
4. Monitoring and Logging       -> Phase 6 (CloudWatch, Prometheus, centralized logging)
5. Incident and Event Response   -> Phase 6 (runbooks, SLOs) + Week 38 (rollback drills)
6. Security and Compliance      -> Phase 2 (KMS/IAM) + Phase 7 (GuardDuty/Config/hardening)

Unlike the associate exams, DOP-C02 assumes you can integrate across all six domains in a single scenario question — 'design a pipeline that deploys safely across regions with automated rollback on a failed canary and full audit logging' touches four domains at once. That's exactly what the capstone build practiced.

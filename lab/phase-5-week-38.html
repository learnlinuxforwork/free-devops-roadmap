1Blue/green and canary deployments on EKS and CodeDeploy

Blue/green with two Services and an Ingress cutover
# green (new) deployment runs alongside blue (current), zero traffic yet
kubectl apply -f deployment-green.yaml
kubectl get pods -l version=green -n roadmap    # confirm healthy before cutover

# cut over instantly by changing the Service selector
kubectl patch service roadmap-api -n roadmap \
  -p '{"spec":{"selector":{"version":"green"}}}'

# keep blue running briefly for instant rollback, then remove it
Canary with a weighted Ingress (NGINX ingress controller annotations)
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: roadmap-api-canary
  annotations:
    nginx.ingress.kubernetes.io/canary: "true"
    nginx.ingress.kubernetes.io/canary-weight: "10"
spec:
  rules:
    - host: api.roadmap.local
      http:
        paths:
          - path: /
            pathType: Prefix
            backend: { service: { name: roadmap-api-v2, port: { number: 80 } } }
The CodeDeploy equivalent for an ECS/Lambda target
aws deploy create-deployment \
  --application-name roadmap-api \
  --deployment-group-name canary-10-percent \
  --deployment-config-name CodeDeployDefault.ECSCanary10Percent5Minutes

Blue/green is an instant, all-or-nothing cutover with an easy rollback. Canary shifts a small percentage of real traffic first, trading a slower rollout for catching a bad deploy before it affects everyone.

2Feature flags and rollback procedures — practice triggering and rolling back a bad deploy

A simple feature flag check — no new infrastructure required
import os

def new_checkout_flow_enabled(user_id):
    return os.environ.get("FEATURE_NEW_CHECKOUT") == "true" or user_id in BETA_USERS
Deliberately ship a broken version, then practice the rollback
helm upgrade roadmap-api ./charts/roadmap-api --set image.tag=v-broken -n roadmap
kubectl rollout status deployment/roadmap-api -n roadmap    # watch it fail readiness

helm rollback roadmap-api -n roadmap        # or:
kubectl rollout undo deployment/roadmap-api -n roadmap
Checkpoint

Time the full rollback from 'I noticed it's broken' to 'traffic is healthy again.' Write that number down — you'll compare it against your Phase 6 incident response runbook and it becomes a real, defensible number in interviews.

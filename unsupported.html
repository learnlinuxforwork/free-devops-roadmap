Microsoft Windows and Microsoft Edge on Windows is not supported

This roadmap, its labs, and every command in them are built and tested on Linux and macOS. Windows isn't part of the plan — that's a deliberate choice, not an oversight, and running Microsoft Edge on Windows doesn't change that. The fastest path forward is to install one of the supported operating systems below.
